# Rota Verde América do Sul 🌿

Bem-vindo ao projeto **Rota Verde**, seu portal de ecoturismo consciente pela América do Sul.

## 🚀 Sobre o Projeto
Este site foi desenvolvido para inspirar viajantes a explorar a beleza natural do continente de forma sustentável, respeitando o meio ambiente e as comunidades locais.

## ✨ Funcionalidades
- Design responsivo e moderno
- Imagens de alta qualidade do Unsplash
- Animações suaves de scroll reveal
- Fontes Google (Poppins) para melhor tipografia
- Seções organizadas: Home, Posts Recentes, Sobre Nós, Destinos e Newsletter
- Rodapé com ícones de redes sociais

## 📁 Estrutura do Projeto
```
/workspace/
├── assets/
│   ├── css/
│   │   └── style.css          # Estilos completos do site
│   ├── js/
│   │   └── script.js          # Lógica de interatividade e animações
│   └── images/                # Diretório para imagens locais (opcional)
├── index.html                 # Página principal
├── README.md                  # Este arquivo
├── AGENTS.md                  # Instruções para assistentes de IA
├── .gitignore                 # Proteção de arquivos sensíveis
└── package.json               # Gerenciamento de dependências
```

## 🎨 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica
- **CSS3**: Estilização moderna com Grid, Flexbox e animações
- **JavaScript (ES6+)**: Interatividade com Intersection Observer
- **Google Fonts**: Tipografia Poppins
- **Unsplash Images**: Banco de imagens profissionais gratuitas

## 🖼️ Imagens
O projeto utiliza imagens de alta qualidade do [Unsplash](https://unsplash.com/) e ícones do [Flaticon](https://www.flaticon.com/), carregados diretamente via CDN, garantindo:
- Carregamento rápido
- Qualidade profissional
- Sem necessidade de download manual

## 🔒 Segurança e Boas Práticas
- **Zero Segredos:** Varredura automática em busca de chaves de API e senhas.
- **Gitignore Robusto:** Impede que arquivos de ambiente (`.env`) ou pastas de sistema sejam publicados acidentalmente.
- **Organização Profissional:** Estrutura modular que facilita a manutenção e auditoria de segurança.
- **Imagens Otimizadas:** Uso de URLs com parâmetros de redimensionamento para melhor performance.

## 🚀 Como Usar
1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Personalize conforme necessário
